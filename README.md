# JavaScript Básico

Repositorio de Miguel Angel Molina Diaz/práctica para aprender los fundamentos de JavaScript paso a paso.

Este proyecto está pensado para personas que están empezando desde cero y quieren entender:

* qué es una variable y cómo se usa
* cómo funcionan los tipos de datos
* cómo escribir condiciones y bucles
* cómo trabajar con strings, arrays, objetos, sets y maps
* cómo crear funciones y clases
* cómo manejar errores
* cómo usar módulos en JavaScript y Node.js
* cómo apoyarse en `console` para depurar código

## Objetivo del repositorio

El objetivo es reunir ejercicios básicos de JavaScript en archivos separados, con comentarios explicativos y ejemplos prácticos, para facilitar el estudio y la comprensión del lenguaje.

Cada archivo representa una clase o ejercicio y muestra cómo funciona una parte concreta del lenguaje.

## Para quién es este repositorio

Este repositorio está orientado a:

* personas que están aprendiendo JavaScript desde cero
* estudiantes que quieren practicar sintaxis básica
* personas que quieren repasar fundamentos de programación
* quien desee ver ejemplos sencillos y claros de código

## Qué contiene

El repositorio incluye ejercicios y ejemplos sobre:

* `console.log`, `console.error`, `console.warn`, `console.table`, etc.
* comentarios en una línea y varias líneas
* variables: `var`, `let` y `const`
* tipos de datos primitivos
* operadores aritméticos, de comparación, lógicos y ternarios
* strings y métodos comunes
* condicionales: `if`, `else`, `else if`, `switch`
* arrays y sus métodos
* sets y maps
* bucles: `for`, `while`, `do...while`, `for...of`
* funciones, parámetros, retorno y funciones flecha
* objetos y objetos anidados
* desestructuración y spread operator
* clases, herencia, getters, setters y propiedades privadas
* manejo de errores con `try`, `catch`, `finally` y `throw`
* módulos con `export`, `import` y módulos nativos de Node.js

## Cómo está organizado

El contenido está dividido en archivos para que cada tema quede separado y sea más fácil de estudiar.

La idea es que cada archivo tenga:

* un tema concreto
* código de ejemplo
* comentarios explicativos
* ejercicios resueltos

Esto ayuda a estudiar por partes y evita tener todo mezclado en un solo archivo.

## Cómo usar este repositorio

1. Abre el proyecto en Visual Studio Code.
2. Revisa cada archivo en orden.
3. Lee los comentarios antes de ejecutar el código.
4. Ejecuta los ejemplos y observa la salida en consola.
5. Modifica los valores para practicar y ver cómo cambia el resultado.
6. Repite los ejercicios hasta entender la sintaxis.

## Recomendación de estudio

Para aprovechar mejor el repositorio:

* primero lee el comentario general del archivo
* después observa cada bloque de código
* ejecuta el archivo en la consola o terminal
* cambia variables, textos y números para practicar
* intenta predecir el resultado antes de ejecutarlo
